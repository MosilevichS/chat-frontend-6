# Мессенджер

## Функциональность

- 💬 **Личные и групповые чаты** 
- 📎 **Отправка файлов** 
- 🔐 **Аутентификация по номеру телефона** 
- 🟢 **Онлайн-статус** 
- 📱 **Адаптивный дизайн**  
- 📋 **Управление контактами** 
- 🔔 **Уведомления** 
- 🔗 **Приглашения по ссылке** 
- ✅ **Статусы доставки и прочтения**

## Технологии

- ⚛️ **React 19** + **Next.js 15** - основной фреймворк
- 📘 **TypeScript** - типизация всего кода
- 🎨 **Tailwind CSS** - стилизация с кастомными CSS-переменными
- 🔄 **Redux Toolkit + RTK Query** - управление состоянием и API-запросами
- 🔌 **WebSocket** - реальное время для сообщений и событий
- 🔐 **JWT** - аутентификация через access/refresh токены


## Структура проекта

- **app** - роутинг и страницы

- **components** - UI-компоненты

- **services** - API

- **store** - глобальное состояние

- **hooks** - кастомные хуки

- **assets** - изображения, шрифты

- **types** - типы и интерфейсы
